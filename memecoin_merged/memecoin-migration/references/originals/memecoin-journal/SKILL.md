# memecoin-journal — сверка токена с журналом

В скилле две базы:
1. **`history.csv.gz` — история ~45 тыс. токенов** Pump.fun (июнь–июль 2026, все 5 689 мигрантов +
   ~40 тыс. немигрантов), снимки на 1, 2 и 5 минуте. Её НЕ читать глазами — только через скрипт
   `find_similar.py` (шаг 2А).
2. **`tokens.csv` — живой журнал Адмира**: токены со скринов Axiom с итогами (шаг 2Б).

В файле `tokens.csv` (рядом с этим файлом) хранятся все токены, которые Адмир уже присылал:
одна строка = один токен, с его данными на момент скрина и **итогом**.
Прочитай `tokens.csv` целиком перед ответом.

## Колонки tokens.csv

`id, date, ticker, pair (SOL/USDC), age_min, mc_usd, sol_price, mc_sol, curve_pct (B.Curve),
ath_usd, holders, top10_pct, dev_h_pct, snipers_pct, insiders_pct, bundlers_pct, buys, sells,
net_usd (Net Vol.), dev_tokens, dev_migrated, mayhem (yes/no), dex_paid (yes/no), reused_img,
est_A, est_B (оценки скилла memecoin-migration-2), result (YES / NO / ?), peak_after_usd, note`

- `result = YES` — мигрировал, `NO` — нет (сдох или завис дольше 30 мин), `?` — итог ещё не известен.
- `peak_after_usd` — максимальная MC, до которой дошёл токен после скрина (если известно).

## Шаг 1. Снять данные с нового скрина Axiom

Возраст, MC ($) и цена SOL (нижняя панель, рядом со значком ≡), B.Curve, ATH, Holders,
Top 10 H, Dev H, Snipers H, Insiders, Bundlers, Buys/Sells (24h), Net Vol., Dev Tokens
(всего / Migrated), Mayhem, Dex Paid, Reused Image Tokens, пара (SOL или USDC).
`mc_sol = mc_usd / sol_price`. Чего нет на скрине — оставь пустым, не выдумывай.

## Шаг 2А. Похожие из истории (главное)

Запусти скрипт (нужен инструмент выполнения кода):

```
python find_similar.py --age <мин> --mc_usd <MC $> --sol <цена SOL> --ath_usd <ATH $> \
    --buys <Buys> --sells <Sells> --net_usd <Net Vol. $> --mayhem <1/0> [--top10 <Top 10 H %>]
```

Запусти **два раза**: без `--top10` и с `--top10` (эксперимент). Скрипт сам берёт токены того же
возраста (1/2/5 мин) и того же Mayhem, находит 300 самых похожих по MC, падению от ATH, покупкам,
продажам и притоку и выдаёт «ШАНС МИГРАЦИИ ПО ПОХОЖИМ» с поправкой на выборку.
Если выполнить код нельзя — скажи Адмиру, что нужно включить «Code execution» в настройках,
и переходи к шагу 2Б.

Проверка на первых 11 живых токенах (27.09.2026): 1 миграция (BLOX), скрипт дал ей 4%,
а фаворитам SLICE/DRAINER — 24–33% (вариант А давал 40–75%). Сумма оценок ≈ 1,6 миграции против
1 реальной — откалиброван лучше варианта А, но угадывать конкретный токен пока не умеет.
В истории НЕТ бандлеров, снайперов, инсайдеров — их оценивай по живому журналу (2Б).

## Шаг 2Б. Похожие из живого журнала tokens.csv

Сравни новый токен со **всеми** строками, где `result` = YES или NO. Для каждой считай «расстояние»
по признакам (чем меньше суммарная разница — тем похожее):

| Признак | Как сравнивать | Вес |
|---|---|---|
| mc_sol | разница в разах (100 vs 200 = сильно, 100 vs 120 = близко) | 3 |
| возраст | 0–1 / 1–3 / 3–6 / 6+ мин — одна группа или нет | 2 |
| curve_pct | разница в процентных пунктах / 10 | 2 |
| top10_pct | разница / 5 | 2 |
| bundlers_pct | разница / 10 | 2 |
| успешность дева | dev_migrated / dev_tokens (новый дев = 0/1) | 2 |
| buys / sells | отношение, разница | 1 |
| snipers + insiders | сумма, разница / 10 | 1 |
| mayhem, пара USDC | совпадает или нет (не совпадает = большая разница) | 3 |
| падение от ATH | (ath − mc) / ath, разница | 1 |

Выбери **3–5 самых похожих** токенов с известным итогом.

## Шаг 3. Ответ Адмиру

1. **Шанс по истории** (обе цифры скрипта) и **похожие токены из живого журнала** — короткая таблица: тикер, MC SOL, Top10, бандлеры, дев, **итог**,
   и одним словом, чем похож.
2. **Вывод по журналу:** «из N похожих мигрировало X». Если похожих с итогом меньше 3 — прямо скажи,
   что журнал пока мал и вывод ненадёжный.
3. **Паттерны:** если новый токен похож на токены с пометкой «разогнали и слили» или на «фабрику дева» —
   предупреди.
4. Если одновременно вызван «мм2» — дай и оценки memecoin-migration-2 (А и Б), и вывод журнала
   рядом, чтобы их можно было сравнить.
5. **Готовая строка для журнала** в блоке кода — в формате tokens.csv, с `result = ?`,
   id = следующий номер после последнего в файле.

## Шаг 4. Итоги

Когда Адмир сообщает итог («мигрировал», «сдох», присылает скрин спустя время) — выдай
**исправленную строку** этого токена (result = YES/NO, peak_after_usd, note). Напомни, что строки
нужно добавить в `tokens.csv` (Адмир отправляет их в Claude Code — там журнал обновляется
в репозитории `gedgafovadmir7-tech/chipichapa`, папка `memecoin_journal/`, и собирается новый ZIP скилла).

## Честность

- Журнал — это десятки токенов, а не сотни тысяч. Совпадение с 3–5 похожими — подсказка, не гарантия.
- Никогда не обещай миграцию или прибыль. Если похожие почти все NO — так и говори: «скорее нет».
