# Архитектура: клон Obsidian (тест, для себя)

## Стек
Next.js (App Router) + TypeScript + Tailwind + SQLite (better-sqlite3) + Drizzle.

| Выбор | Почему |
|---|---|
| Next.js + TS | один проект на фронт и API, по умолчанию из скила |
| Tailwind с токенами | токены этапа 3 подключаются в тему |
| SQLite вместо Postgres | отклонение от скила: один пользователь, тест, ноль настройки; файл БД лежит рядом. FTS5 даёт поиск из коробки |
| Без авторизации и платежей | «для себя», тест. Если когда-то выпускать — добавить Auth.js и user_id в vault |
| CodeMirror 6 | редактор Markdown с расширениями (автодополнение `[[`, подсветка, Live Preview через декорации) |
| d3-force + canvas | граф: физика и отрисовка на 1000+ узлов |
| Один процесс | микросервисов нет |

Хостинг: локально (`next dev`/`next start`). Деплой — позже, если понадобится.

## Схема
См. `schema.sql`: 7 таблиц (vault, folder, note, link, tag, setting + виртуальная note_fts). Ссылки и теги — производные, пересчитываются при каждом сохранении заметки.

## Что кусается
| Тема | Решение |
|---|---|
| Переименование заметки | в одной транзакции обновить `target_text` у входящих ссылок и переписать `[[старое]]` в content источников |
| Ссылка на ещё не созданную заметку | `to_note_id = NULL`; при создании заметки с таким именем — резолвить все висящие ссылки |
| Регистр и кириллица | уникальность и поиск через `COLLATE NOCASE` / unicode61; для кириллицы NOCASE в SQLite не работает → хранить поле `title_key` в нижнем регистре, считаемое в коде (добавить при сборке) |
| Парсинг ссылок/тегов | не трогать код-блоки и inline-код; `#` в заголовках не тег; тест на это |
| Гонки сохранения | автосохранение с debounce, `updated_at` как версия: при несовпадении — предупреждение (две вкладки) |
| Производительность графа | отдавать только id/title/рёбра; на клиенте d3-force, отрисовка canvas; лимит и фильтры при >2000 узлов |
| Часовые пояса | время в UTC; дату «сегодня» для ежедневной заметки передаёт клиент по локальному времени |
| Большие заметки | лимит размера content (например 2 МБ) |
| Удаление данных | `ON DELETE CASCADE` от vault; удаление vault стирает всё |

Не применимо в тесте: реалтайм, офлайн, мультитенантность, почта, GDPR.

## Порядок сборки
1. **Вертикальный срез** — S02, S03, S04 (Source-режим): создать vault, создать заметку, написать, сохранить. Таблицы vault, folder, note. Маршруты: vaults, tree, notes CRUD.
2. **Must** — связи и поиск: `[[ссылки]]` с автодополнением и резолвом (link), обратные ссылки S07, переименование с обновлением ссылок, переключатель S05, поиск S06 (note_fts), Reading view, граф S08 (graph).
3. **Should** — теги S09 (tag), ежедневные заметки S10, вкладки, локальный граф, алиасы и заголовки в ссылках, Live Preview (последним).
4. **Could** — палитра команд S11, темы S12, операторы поиска, фильтры графа, unlinked mentions.
5. Улучшения по отзывам пользователей — вне теста.
