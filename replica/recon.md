# Разведка: Obsidian (тестовый клон, веб, для себя)

**Объём:** основной цикл (хранилище заметок, Markdown-редактор, вики-ссылки, обратные ссылки, поиск, теги, ежедневные заметки) + граф связей.
**Платформа:** веб (Next.js), по умолчанию — пользователь не выбрал. **Аудитория:** для себя, тест, без платежей.
**Условия использования:** Obsidian бесплатен для личного использования, аккаунт не нужен. Работаем только по публичной справке (help.obsidian.md), без чужих аккаунтов и кода.

## Потоки
| ID | Цель | Путь | Клики (счастливый путь) | Крайние случаи |
|---|---|---|---|---|
| F01 | Создать заметку и написать | S02 → S03 «Новая заметка» → S04 | 2 | дублирующее имя, спецсимволы в имени |
| F02 | Связать заметки `[[...]]` | S04: ввод `[[` → автодополнение | 1 + выбор | ссылка на несуществующую (создаётся по клику), алиас `[[a\|b]]`, заголовок `[[a#h]]` |

| F04 | Посмотреть обратные ссылки | S04 → S07 | 1 | переименование заметки обновляет ссылки |
| F05 | Исследовать граф | S08 | 1 | 1000+ узлов, изолированные заметки, фильтр по тегу |
| F06 | Ежедневная заметка | S10 | 1 | часовой пояс, смена дня |
| F07 | Теги `#tag` | S04 ввод → S09 | 1 | вложенные теги `#a/b` |

## Компоненты
Дерево файлов, вкладки (с закрытием/перетаскиванием), редактор Markdown, автодополнение ссылок, боковая панель (сворачиваемая), модальное окно-палитра (switcher/commands), граф-canvas, список результатов поиска, тост-уведомления, контекстное меню.

## Предполагаемая модель данных
| Сущность | Поля | Доказательство | Уверенность |
|---|---|---|---|
| vault | id, name, owner | справка: «vault — папка с заметками» | высокая |
| note | id, vault_id, path, title, content, created_at, updated_at | файлы .md в папке | высокая |
| folder | id, vault_id, parent_id, name | дерево в проводнике | высокая |
| link | from_note_id, to_note_id/target_text, alias, heading | вики-ссылки, обратные ссылки | высокая |
| tag | note_id, name | `#tag` в тексте | высокая |
| settings | theme, hotkeys | настройки | средняя |

Ссылки и теги — производные: пересчитываются парсингом `content` при сохранении.

## Размер
12 экранов, 7 потоков, 6 сущностей. Размер **S–M** (граф и живое превью — самое трудное).
Сложные части: 1) Live Preview-редактор; 2) граф с физикой на большом числе узлов; 3) переименование с обновлением ссылок по всему vault.
